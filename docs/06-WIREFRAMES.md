# 06 — Screen-by-Screen Wireframes (RTL)

**الهيكل العام**
```
Desktop                                   Mobile
┌───────┬───────────────────────────┐     ┌─────────────────────┐
│Sidebar│ Topbar: date · water+ · ☀ │     │ Topbar              │
│ (11)  ├───────────────────────────┤     ├─────────────────────┤
│       │ Page header               │     │ Page                │
│       │ Content                   │     │                     │
└───────┴───────────────────────────┘     ├─────────────────────┤
                                          │ 4 tabs + المزيد     │
                                          └─────────────────────┘
```

**Dashboard (`/`)**
```
[ تحية + التاريخ ]                               [التحليلات الذكية]
[ Hero: Ring درجة اليوم | الجلسة القادمة + ابدأ | Growth: دهون/عضلات/وزن ]
[KPI×5: وزن · دهون · SMM · سعرات · بروتين]
[KPI×5: ماء · تمارين · أدوية · نوم · التزام الغذاء]
[ جدول اليوم (جرعات) ]  [ Insights (4) ]
[ تكوين الجسم ]         [ سعرات/بروتين 14 يوم ]
[ حجم التمرين ]         [ Heatmap + اختيار المقياس + تفاصيل اليوم ]
```
**التغذية:** Tabs (اليوم/الأسبوع/الشهر/الدليل). اليوم: Ring سعرات + ماكروز + شرائط الحصص، 4 بطاقات وجبات (Stepper لكل مجموعة، زر «حسب الخطة»)، أكل خارج الخطة.
**الماء:** Ring كبير، 8 كؤوس قابلة للنقر، أزرار 250/500/مخصص، Streak، رسم 14 يوم، Heatmap، توزيع الساعات.
**الأدوية:** شريط الالتزام اليومي/الأسبوعي، قائمة الجرعات بالمواعيد (✓ / تخطي)، الفائتة، إدارة الأدوية والمواعيد.
**التمارين:** Tabs (تسجيل/السجل/التقدم/البرنامج). التسجيل: اختيار Split، بطاقة لكل تمرين: توصية الحمل، آخر مرة، صفوف (وزن·عدات·RIR·RPE)، مؤقت راحة عائم.
**القياسات / الصور / النوم / التحليلات / التقارير / الإعدادات:** نماذج إدخال في Dialog، رسوم Recharts، مقارنة صور (سلايدر)، ارتباطات النوم، بطاقات Insight بأربعة ألوان.
