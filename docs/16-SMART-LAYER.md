# 16 — الطبقة الذكية (v1.5)

**المبدأ:** كل ما أُضيف هنا *قراءة واستنتاج فقط*. لم يُعدَّل أي شيء في النظام الغذائي (الحصص، `MEAL_TARGETS`، `EXCHANGE`، صفحة التغذية) ولا في برنامج التمرين (التمارين، المجاميع، الدورة، صفحة التمارين، `overloadAdvice`). الملفات `nutrition/page.tsx` و`workouts/page.tsx` و`seed.ts` و`analytics.ts` كما هي بايت ببايت.

## ما يفعله `intel.ts`
- **weightTrend / weightProjection:** انحدار خطي على الأوزان → معدل الأسبوع، تاريخ الوصول المتوقع للهدف، كشف الثبات (Plateau)، مستوى الثقة.
- **readiness:** جاهزية 0–100 من النوم (40%) والطاقة (20%) والاستشفاء (20%) والتغذية/الماء أمس (20%). نصيحتها «نفّذ البرنامج كما هو» — لا تقترح تغيير جلسة.
- **waterPace / mealStates / proteinPace:** إيقاع الماء مقابل الساعة، ومواعيد الوجبات من الإعدادات، والبروتين المتبقي.
- **energyBalance:** تقدير TDEE = BMR (InBody) × معامل نشاط من جلساتك. معلومة فقط، الهدف الرسمي 1595 يبقى كما هو.
- **medPatterns:** الالتزام حسب وقت اليوم وحسب الدواء، سلسلة الأيام الكاملة.
- **strengthOutlook:** أسبوع البرنامج (من 12)، التمارين الصاعدة/الثابتة، إشارة إجهاد استرشادية (لا تعدّل البرنامج).
- **energyCorrelations / weekdayPattern / focusArea:** ما يرفع طاقتك، أضعف أيام الأسبوع، وأضعف مجال يستحق التركيز.
- **weeklyStory:** ملخص الأسبوع الماضي (إنجازات + فجوات) مقارنًا بما قبله.
- **coachPlan:** «ماذا أفعل الآن؟» مرتبة (عاجل/الآن/قريبًا).
- **progression:** نقاط XP ومستويات و10 أوسمة.
- **extraInsights:** تُضاف تلقائيًا إلى صفحة التحليلات ولوحة التحكم.

## تعديلات صغيرة على ملفات قائمة
`constants.ts` (إضافة عنصرين في `NAV` فقط) · `app-shell.tsx` (زر البحث + اختصار + فئات الطباعة) · `page.tsx` (شريط المدرب) · `insights/page.tsx` (دمج التحليلات الإضافية) · `settings` + `data-provider` (استعادة نسخة JSON، دمج بلا حذف) · `globals.css` (CSS الطباعة).

## لا تغييرات في قاعدة البيانات
تستخدم الحقل الموجود `daily_checkins.energy`؛ لا حاجة لأي Migration.

# v1.6 — ذكاء وتفاعل أعمق

## جديد
| الميزة | أين | الوصف |
|---|---|---|
| **اسأل المدرب** | `/coach` + `Ctrl+K` | شات محلي بالعامية (`lib/coach-chat.ts`) يجيب من بياناتك: «أعمل إيه دلوقتي؟»، «جاهز أتمرن؟»، «هوصل لهدفي إمتى؟»… بدون إنترنت. يرفض بأدب أي طلب لتغيير جرعة أو نظام غذائي أو برنامج تمرين ويحوّلك للدكتور/المدرب. |
| **تحدّي الأسبوع** | الداشبورد + `/coach` | يُولَّد من أضعف مجال لديك (ماء/أدوية/تغذية/نوم/تمرين) ويتحدّث لحظيًا. |
| **مراجعة اليوم + معاينة بكرة** | `/coach` + الداشبورد بعد 7 م | درجة اليوم، إنجازات وفجوات، جلسة الغد حسب دورتك، أول جرعة، وملاحظة يومية (تُحفظ في `daily_checkins.notes` الموجود). |
| **محاكي «لو التزامي كان…»** | `/coach` | شريط 50–100% يعيد رسم توقّع الوصول للوزن (تقدير تقريبي). |
| **احتفالات** | كل الصفحات | إشعار + كونفيتي عند أول تحقيق لهدف الماء/الجرعات/الوجبات/التمرين، أو مستوى/وسام جديد. تحترم `prefers-reduced-motion`. |
| **تنبيهات تكيّفية** | `reminders.ts` | جرعة لم تُسجَّل بعد ساعة · بروتين متبقٍّ 7 م · جاهزية منخفضة قبل التمرين · ملخص نهاية اليوم. تحترم مفاتيح التذكير الحالية. |
| **سؤال من الباحث** | `Ctrl+K` | اكتب أي جملة ← «اسأل المدرب: …» (`/coach?ask=`). |

## ضمانات
- لا تغيير في الحصص أو الخطة الغذائية أو التمارين أو المجاميع أو الدورة (نفس الملفات متطابقة بايت ببايت).
- لا Migration: كل شيء على حقول موجودة (`energy`, `notes`).
- لا مفاتيح API ولا إرسال بيانات لأي طرف: الذكاء كله داخل المتصفح.
