**الطبيب المعالج:** د. أحمد عبد العزيز — أخصائي التغذية العلاجية (Nutri-clinic)

## 1. الرؤية

## 5. متطلبات غير وظيفية
- **UX:** عربي RTL، Dark/Light، Glassmorphism، حركات سلسة (Framer Motion)، Mobile-first مع Bottom Nav.
- **الأمان:** Supabase Auth + RLS على كل جدول (`user_id = auth.uid()`)، Bucket صور خاص بـ Signed URLs.
- **الأداء:** First Load ≤ ~390KB/صفحة، التحميل المبدئي مرة واحدة ثم Optimistic Updates.
- **الاعتمادية:** وضع محلي (localStorage) يعمل بلا إنترنت/Supabase.
- **الخصوصية:** مستخدم واحد، لا تتبع طرف ثالث.
- **سلامة طبية:** التطبيق يتابع الالتزام فقط ولا يقترح تغيير جرعات أو نظام.

## 6. قواعد الحساب
- **Food Compliance** = 1 − (Σ|المتناول − المقرر| + سعرات خارج الخطة/80) ÷ Σالمقرر.
- **Medication Day %** = الجرعات المأخوذة ÷ المقررة. الجرعة تُعد فائتة بعد 3 ساعات من موعدها.
- **e1RM (Epley)** = وزن × (1 + (عدات + RIR)/30)، بحد أقصى 15.
- **Progressive Overload (Double Progression):** كل المجموعات عند أعلى المدى مع RIR ≥ 1 ← +2.5 كجم (+5 للأرجل)، وإلا +1 عدة.
- **Sleep Score** = مدة (60) + موعد النوم مقابل 23:00 (25) + الجودة (15).
- **Daily Score** = متوسط (التغذية، الماء، الأدوية، التمرين، النوم) المتاح لذلك اليوم.
- **بداية الأسبوع:** السبت.
