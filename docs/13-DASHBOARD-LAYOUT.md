# 13 — Dashboard Layout

| المنطقة | المحتوى | المصدر |
|---|---|---|
| Hero | درجة اليوم (0–100)، الجلسة القادمة في دورة A/P، النمو منذ أول InBody | `dayScores`, `nextSplit` |
| KPI ×10 | الوزن · الدهون · SMM · السعرات · البروتين · الماء · التمارين · الأدوية · النوم · التزام الغذاء، كلٌ مع Trend/Sparkline/Ring | `latestValue`, `dayNutrition`, `medDay` … |
| جدول اليوم | جرعات مستحقة/فائتة/قادمة | `slotsOn` |
| Insights | أعلى 4 حسب الخطورة | `generateInsights` |
| Charts | تكوين الجسم (3 محاور) · سعرات/بروتين 14 يومًا · حجم التمرين الأسبوعي | Recharts |
| Heatmap | 12 أسبوعًا، 6 مقاييس، تفاصيل اليوم عند النقر | `scoreSeries` |

شبكة KPI: 2 أعمدة (موبايل) ← 3 (لابتوب) ← 5 (شاشة كبيرة).
